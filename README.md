# Lucky Numbers

Gerador de números da loteria americana (Powerball, Mega Millions, Lotto America, Millionaire for Life).

## Publicar no Netlify

1. Extraia este zip.
2. No [Netlify](https://app.netlify.com): **Add new site → Import an existing project**.
3. Confirme:
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
   - **Node:** 22
4. Deploy.

O `netlify.toml` já traz esses valores. Não precisa de variáveis de ambiente.
